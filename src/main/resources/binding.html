راهنمای کامل Binding در JavaFX

در JavaFX مفهوم Binding یکی از مهم‌ترین قابلیت‌ها برای ارتباط دادن قسمت‌های مختلف رابط کاربری، Model و Propertyها است.

Binding به زبان ساده یعنی:

اگر مقدار یک Property تغییر کرد، مقدار Property وابسته نیز به صورت خودکار تغییر کند.

1. Binding چیست؟

فرض کنید یک TextField و یک Label داریم: 

TextField
    |
    | Binding
    v
Label

اگر بنویسیم: 

result.textProperty().bind(
        textField.textProperty()
);

هر چیزی که در TextField نوشته شود، به صورت خودکار در Label نمایش داده می‌شود. 

TextField = "Ali"

        |
        | Binding
        v

Label = "Ali"

2. Property در JavaFX چیست؟

JavaFX برخلاف Java معمولی، نوع خاصی از متغیرها به نام Property دارد.

مثلاً: 

StringProperty name =
        new SimpleStringProperty();

یا: 

IntegerProperty age =
        new SimpleIntegerProperty();

انواع مهم Property عبارت‌اند از:

Property نوع داده
StringProperty String
IntegerProperty int
LongProperty long
DoubleProperty double
FloatProperty float
BooleanProperty boolean
ObjectProperty<T> Object

3. تفاوت Property با متغیر معمولی

متغیر معمولی:

private String name;

public String getName() {
    return name;
}

public void setName(String name) {
    this.name = name;
}

اما در JavaFX می‌توانیم Property داشته باشیم: 

private final StringProperty name =
        new SimpleStringProperty();

public String getName() {
    return name.get();
}

public void setName(String value) {
    name.set(value);
}

public StringProperty nameProperty() {
    return name;
}

متد مهم اینجا: 

nameProperty()

است؛ زیرا برای Binding به Property نیاز داریم.

4. ساده‌ترین Binding

فرض کنید: 

@FXML
private TextField textField;

@FXML
private Label result;

در initialize: 

result.textProperty().bind(
        textField.textProperty()
);

رابطه:

TextField.textProperty() | | bind v Label.textProperty()

5. Binding یک‌طرفه

متد: 

bind()

یک Binding یک‌طرفه ایجاد می‌کند. 

A  ----------->  B

مثلاً: 

label.textProperty().bind(
        textField.textProperty()
);

در این حالت TextField منبع است و Label مقصد.

وقتی Property مقصد با bind() متصل شده باشد، دیگر نباید با set() مقدار آن را تغییر دهید.

6. حذف Binding

برای حذف Binding: 

label.textProperty().unbind();

بعد از unbind می‌توانیم دوباره مقدار Label را تغییر دهیم: 

label.textProperty().unbind();

label.setText("Hello");

7. Binding دوطرفه

اگر می‌خواهیم تغییر هر دو طرف روی طرف مقابل اعمال شود: 

bindBidirectional()

مثلاً: 

textField1.textProperty()
        .bindBidirectional(
                textField2.textProperty()
        );

رابطه: 

TextField1  <---------->  TextField2

اگر TextField اول تغییر کند، دوم تغییر می‌کند و بالعکس.

برای حذف: 

textField1.textProperty()
        .unbindBidirectional(
                textField2.textProperty()
        );

8. Binding با StringProperty

private final StringProperty name =
        new SimpleStringProperty();

@FXML
private Label label;

در initialize: 

label.textProperty().bind(name);

سپس: 

name.set("Ali");

Label خودکار مقدار Ali را نمایش می‌دهد.

9. Binding عددی

مثلاً: 

IntegerProperty count =
        new SimpleIntegerProperty(10);

برای نمایش آن در Label: 

label.textProperty().bind(
        count.asString()
);

اگر بنویسیم: 

count.set(100);

Label خودکار 100 را نمایش می‌دهد.

10. asString()

برای تبدیل Property عددی به String از asString() استفاده می‌کنیم. 

IntegerProperty number =
        new SimpleIntegerProperty(10);

label.textProperty().bind(
        number.asString()
);

برای Double: 

DoubleProperty price =
        new SimpleDoubleProperty(125.5);

label.textProperty().bind(
        price.asString("%.2f")
);

نتیجه: 

125.50

11. Binding با concat()

برای اتصال چند String: 

label.textProperty().bind(
        textField1.textProperty()
                .concat(" - ")
                .concat(textField2.textProperty())
);

اگر: 

TextField1 = 100
TextField2 = 200

نتیجه: 

100 - 200

12. Bindings.format()

برای ساخت یک String از چند Property: 

label.textProperty().bind(
        Bindings.format(
                "نام: %s - نام خانوادگی: %s",
                firstName,
                lastName
        )
);

مثلاً: 

نام: علی - نام خانوادگی: احمدی

13. createStringBinding()

یکی از مهم‌ترین متدهای Binding: 

Bindings.createStringBinding()

زمانی استفاده می‌شود که منطق محاسباتی خاصی داریم. 

label.textProperty().bind(
        Bindings.createStringBinding(
                () -> {

                    return textField1.getText()
                            + " "
                            + textField2.getText();
                },

                textField1.textProperty(),
                textField2.textProperty()
        )
);

پارامترهای آخر، Dependencyهای Binding هستند.

14. Dependency چیست؟

در مثال بالا: 

textField1.textProperty()
textField2.textProperty()

Dependency هستند.

TextField1 ──────┐ | v createStringBinding | v Label TextField2 ──────┘

هرگاه یکی از آن‌ها تغییر کند، Binding دوباره محاسبه می‌شود.

15. BooleanBinding

برای شرایط منطقی از Boolean Binding استفاده می‌شود.

مثلاً: 

textField.textProperty().isEmpty()

یک وضعیت Boolean تولید می‌کند.

مثلاً Button را تا زمانی که TextField خالی است غیرفعال کنیم: 

button.disableProperty().bind(
        textField.textProperty().isEmpty()
);

16. استفاده از or()

فرض کنید دو TextField داریم و اگر یکی از آن‌ها خالی باشد Button غیرفعال شود: 

button.disableProperty().bind(

        textField1.textProperty().isEmpty()
                .or(
                    textField2.textProperty().isEmpty()
                )

);

یعنی: 

TextField1 خالی
       OR
TextField2 خالی
       |
       v
Button disabled

17. استفاده از and()

برای ترکیب شرایط منطقی می‌توانیم از: 

.and()

استفاده کنیم.

مثلاً: 

condition1.and(condition2)

18. استفاده از not()

برای معکوس کردن Boolean: 

textField.textProperty()
        .isEmpty()
        .not()

یعنی TextField خالی نیست.

مثلاً: 

button.disableProperty().bind(
        textField.textProperty()
                .isEmpty()
                .not()
);

توجه کنید که این مثال باعث می‌شود Button وقتی TextField پر است غیرفعال شود؛ بنابراین در عمل باید شرط موردنظر را دقیق انتخاب کنید.

19. Bind کردن visible

errorLabel.visibleProperty().bind(
        textField.textProperty().isEmpty()
);

اگر TextField خالی باشد، errorLabel نمایش داده می‌شود.

20. Bind کردن managed

در Layoutهایی مانند VBox و HBox معمولاً بهتر است managedProperty() را نیز Bind کنیم. 

BooleanBinding showError =
        textField.textProperty().isEmpty();

errorLabel.visibleProperty().bind(showError);

errorLabel.managedProperty().bind(showError);

در این حالت وقتی Label مخفی می‌شود، فضای آن نیز از Layout حذف می‌شود.

21. Bind کردن disable

button.disableProperty().bind(
        textField.textProperty().isEmpty()
);

یکی از رایج‌ترین کاربردهای Binding در فرم‌های JavaFX است.

22. Bindings.when()

این قابلیت مشابه if/else است. 

label.textProperty().bind(
        Bindings.when(
                textField.textProperty().isEmpty()
        )
        .then("لطفاً مقدار وارد کنید")
        .otherwise("مقدار وارد شده است")
);

اگر TextField خالی باشد: 

لطفاً مقدار وارد کنید

در غیر این صورت: 

مقدار وارد شده است

23. Binding به چند Property

می‌توانیم چند Property را در یک Binding استفاده کنیم. 

label.textProperty().bind(
        Bindings.createStringBinding(
                () -> {

                    double a =
                            Double.parseDouble(
                                    textField1.getText()
                            );

                    double b =
                            Double.parseDouble(
                                    textField2.getText()
                            );

                    return String.valueOf(a + b);
                },

                textField1.textProperty(),
                textField2.textProperty()
        )
);

24. مثال کامل ماشین حساب

FXML

<VBox spacing="15">

    <TextField
            fx:id="textFieldNumber1"
            promptText="عدد اول"/>

    <ComboBox
            fx:id="operatorComboBox"/>

    <TextField
            fx:id="textFieldNumber2"
            promptText="عدد دوم"/>

    <Label
            fx:id="result"/>

</VBox>

Controller

import javafx.beans.binding.Bindings;
import javafx.fxml.FXML;
import javafx.scene.control.ComboBox;
import javafx.scene.control.Label;
import javafx.scene.control.TextField;

public class CalculatorController {

    @FXML
    private TextField textFieldNumber1;

    @FXML
    private TextField textFieldNumber2;

    @FXML
    private ComboBox<String> operatorComboBox;

    @FXML
    private Label result;


    @FXML
    public void initialize() {

        operatorComboBox.getItems().addAll(
                "+",
                "-",
                "*",
                "/"
        );

        operatorComboBox.getSelectionModel()
                .selectFirst();


        result.textProperty().bind(

                Bindings.createStringBinding(

                        this::calculate,

                        textFieldNumber1.textProperty(),
                        textFieldNumber2.textProperty(),
                        operatorComboBox.valueProperty()
                )
        );
    }


    private String calculate() {

        try {

            double number1 =
                    Double.parseDouble(
                            textFieldNumber1.getText()
                    );

            double number2 =
                    Double.parseDouble(
                            textFieldNumber2.getText()
                    );

            String operator =
                    operatorComboBox.getValue();


            if (operator == null) {
                return "عملگر را انتخاب کنید";
            }


            return switch (operator) {

                case "+" ->
                        String.valueOf(
                                number1 + number2
                        );

                case "-" ->
                        String.valueOf(
                                number1 - number2
                        );

                case "*" ->
                        String.valueOf(
                                number1 * number2
                        );

                case "/" -> {

                    if (number2 == 0) {
                        yield "تقسیم بر صفر مجاز نیست";
                    }

                    yield String.valueOf(
                            number1 / number2
                    );
                }

                default ->
                        "عملگر نامعتبر";
            };

        } catch (NumberFormatException e) {

            return "عدد نامعتبر";
        }
    }
}

25. جریان Binding در ماشین حساب

TextField Number 1 | | +------------------+ | TextField Number 2 | | | +------------------+----> calculate() | ComboBox Operator | | | +------------------+ | v Label Result

یعنی سه Property به Binding وابسته هستند: 

textFieldNumber1.textProperty()

textFieldNumber2.textProperty()

operatorComboBox.valueProperty()

اگر هرکدام تغییر کند، محاسبه دوباره انجام می‌شود.

26. Binding در Model

Binding فقط مخصوص کنترل‌های UI نیست. می‌توانیم Model خود را نیز دارای Property کنیم. 

public class Person {

    private final StringProperty firstName =
            new SimpleStringProperty();

    private final StringProperty lastName =
            new SimpleStringProperty();


    public String getFirstName() {
        return firstName.get();
    }


    public void setFirstName(String value) {
        firstName.set(value);
    }


    public StringProperty firstNameProperty() {
        return firstName;
    }


    public String getLastName() {
        return lastName.get();
    }


    public void setLastName(String value) {
        lastName.set(value);
    }


    public StringProperty lastNameProperty() {
        return lastName;
    }
}

27. اتصال TextField به Model

می‌توانیم TextField را به Model متصل کنیم: 

textField.textProperty()
        .bindBidirectional(
                person.firstNameProperty()
        );

حالا: 

TextField
    <------------>
Person.firstNameProperty()

اگر کاربر TextField را تغییر دهد، Model نیز تغییر می‌کند. و اگر Model تغییر کند، TextField نیز تغییر می‌کند.

28. Binding در TableView

یکی از کاربردهای بسیار مهم Property در JavaFX، نمایش اطلاعات در TableView است. 

TableColumn<Person, String> firstNameColumn;

firstNameColumn.setCellValueFactory(
        cellData ->
                cellData.getValue()
                        .firstNameProperty()
);

در این حالت TableView مستقیماً به Property مدل متصل است.

29. Binding و ObservableValue

متدهای Binding معمولاً با نوع: 

ObservableValue<T>
کار می‌کنند.

Propertyهای JavaFX مانند: 

StringProperty
IntegerProperty
BooleanProperty
ObjectProperty
قابلیت Observable بودن دارند.

یعنی JavaFX می‌تواند متوجه شود که مقدار آن‌ها تغییر کرده است.

30. Listener در مقابل Binding

Binding و Listener دو مفهوم متفاوت هستند.

Listener

textField.textProperty()
        .addListener(
                (observable, oldValue, newValue) -> {

                    result.setText(newValue);
                }
        );

Binding

result.textProperty().bind(
        textField.textProperty()
);

Listener زمانی مناسب است که بخواهیم هنگام تغییر مقدار، یک عملیات خاص انجام دهیم.

Binding زمانی مناسب است که بخواهیم یک Property را به Property یا محاسبه دیگری وابسته کنیم.

33. یک نکته بسیار مهم

وقتی یک Property را Bind می‌کنید، مقصد دیگر تحت کنترل مستقیم شما نیست.

مثلاً: 

label.textProperty().bind(
        textField.textProperty()
);

بعد از آن نباید بنویسید: 

label.setText("Hello");

ابتدا باید: 

label.textProperty().unbind();

و سپس مقداردهی کنید.

34. جمع‌بندی

مهم‌ترین مفهوم Binding این است:

به جای اینکه هر بار بعد از تغییر مقدار، خودمان UI را به‌روزرسانی کنیم، یک رابطه بین Propertyها ایجاد می‌کنیم و JavaFX این کار را انجام می‌دهد.

برای شروع، این چهار مورد را به خوبی یاد بگیرید:

  1. bind()
  2. bindBidirectional()
  3. Bindings.createStringBinding()
  4. Bindings.when()

بعد از این چهار مورد، مفاهیم Property، ObservableValue، BooleanBinding، StringBinding و Binding بین Model و View بسیار راحت‌تر قابل درک خواهند بود.
