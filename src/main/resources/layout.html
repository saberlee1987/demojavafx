راهنمای Layout Pane های JavaFX

آشنایی با BorderPane، VBox، HBox، StackPane، AnchorPane، GridPane و سایر Layoutها

```

1. Pane چیست؟

در JavaFX، اجزایی مانند BorderPane، VBox، HBox، StackPane و AnchorPane برای چیدمان عناصر صفحه استفاده می‌شوند.

به این اجزا معمولاً Layout Pane یا Layout Container گفته می‌شود.

وظیفه Pane این است که مشخص کند کنترل‌هایی مانند Button، Label، TextField و TableView چگونه و در کجا قرار بگیرند.

Node │ ├── Control │ ├── Button │ ├── Label │ ├── TextField │ ├── TableView │ └── ComboBox │ └── Parent │ └── Pane ├── BorderPane ├── VBox ├── HBox ├── StackPane ├── AnchorPane ├── GridPane ├── FlowPane ├── TilePane └── Pane

2. VBox

نام VBox مخفف Vertical Box است.

عناصر داخل VBox به صورت عمودی، یعنی زیر یکدیگر، قرار می‌گیرند. 

<VBox spacing="10">

<Label text="نام"/>

<TextField/>

<Label text="نام خانوادگی"/>

<TextField/>

<Button text="ذخیره"/>
```
```
``` ┌──────────────────────┐ │ نام │ │ [**************] │ │ │ │ نام خانوادگی │ │ [**************] │ │ │ │ [ ذخیره ] │ └──────────────────────┘
```

کاربردهای مناسب

  • فرم‌های عمودی
  • منوها
  • قرار دادن چند کنترل زیر یکدیگر
  • صفحه‌های ساده مدیریتی

مثال در صفحه Person

<VBox spacing="15">

<Label text="لیست اشخاص"/>

<HBox>
    ...
</HBox>

<TableView/>

<Pagination/>
```
```

3. HBox

HBox مخفف Horizontal Box است و عناصر را به صورت افقی در کنار یکدیگر قرار می‌دهد. 

<HBox spacing="10">

<Button text="ذخیره"/>

<Button text="ویرایش"/>

<Button text="حذف"/>
```
```
``` ┌──────────────────────────────────┐ │ [ذخیره] [ویرایش] [حذف] │ └──────────────────────────────────┘
```

کاربردها

  • قرار دادن چند دکمه کنار هم
  • Toolbar
  • قسمت جستجوی صفحه
  • چیدن Label و TextField کنار هم

4. BorderPane

BorderPane یکی از مهم‌ترین Layoutهای JavaFX است. این Pane صفحه را به پنج ناحیه تقسیم می‌کند:

  • Top
  • Bottom
  • Left
  • Right
  • Center
TOP ┌─────────────────────────────┐ │ │ ├────────┬───────────┬────────┤ │ │ │ │ │ LEFT │ CENTER │ RIGHT │ │ │ │ │ ├────────┴───────────┴────────┤ │ BOTTOM │ └─────────────────────────────┘ 
<BorderPane>

<top>
    <Label text="Header"/>
</top>

<left>
    <VBox>
        <Button text="Home"/>
        <Button text="Persons"/>
    </VBox>
</left>

<center>
    <TableView/>
</center>

<bottom>
    <Pagination/>
</bottom>
```
```

کاربرد اصلی

برای ساختار اصلی برنامه بسیار مناسب است. مثلاً:

``` ┌─────────────────────────────────────┐ │ Header │ ├──────────┬──────────────────────────┤ │ │ │ │ Sidebar │ Content │ │ │ │ │ │ │ ├──────────┴──────────────────────────┤ │ Footer │ └─────────────────────────────────────┘
```

5. StackPane

StackPane عناصر را روی یکدیگر قرار می‌دهد. عنصر دوم می‌تواند روی عنصر اول قرار بگیرد. 

<StackPane>

<Rectangle width="300" height="200"/>

<Label text="سلام"/>
```
```
``` ┌──────────────────────┐ │ │ │ سلام │ │ │ └──────────────────────┘
```

کاربردها

  • وسط‌چین کردن محتوا
  • قرار دادن متن روی تصویر
  • Overlay
  • نمایش Loading روی صفحه
  • ساخت UIهای Responsive

مثال

<StackPane>

<ImageView/>

<Label text="عکس پروفایل"/>
```
```

6. AnchorPane

AnchorPane امکان تعیین فاصله یک کنترل از لبه‌های والد را فراهم می‌کند. 

<AnchorPane>

<Button text="ذخیره"
        AnchorPane.rightAnchor="10"
        AnchorPane.bottomAnchor="10"/>
```
```
``` ┌──────────────────────────────┐ │ │ │ │ │ │ │ [ذخیره]│ └──────────────────────────────┘ ↑ 10px فاصله
```

مثال بسیار مهم

<TableView
AnchorPane.topAnchor="10"
AnchorPane.bottomAnchor="10"
AnchorPane.leftAnchor="10"
AnchorPane.rightAnchor="10"/>

در این حالت TableView در هر چهار جهت ۱۰ پیکسل فاصله دارد و با تغییر اندازه پنجره، اندازه آن نیز تغییر می‌کند.

7. GridPane

GridPane صفحه را به ردیف و ستون تقسیم می‌کند. به همین دلیل برای ساخت فرم‌ها بسیار مناسب است.

Column 0 Column 1 ┌──────────────┬──────────────┐ │ نام │ TextField │ ├──────────────┼──────────────┤ │ نام خانوادگی │ TextField │ ├──────────────┼──────────────┤ │ موبایل │ TextField │ └──────────────┴──────────────┘ 
<GridPane hgap="10" vgap="10">

<Label text="نام"
       GridPane.rowIndex="0"
       GridPane.columnIndex="0"/>

<TextField
       GridPane.rowIndex="0"
       GridPane.columnIndex="1"/>

<Label text="نام خانوادگی"
       GridPane.rowIndex="1"
       GridPane.columnIndex="0"/>

<TextField
       GridPane.rowIndex="1"
       GridPane.columnIndex="1"/>
```
```

کاربرد

برای فرم ثبت شخص، اطلاعات مشتری، کارمند، حساب بانکی و مانند آن بسیار مناسب است.

8. FlowPane

FlowPane عناصر را پشت سر هم قرار می‌دهد و زمانی که فضای کافی وجود نداشته باشد، آیتم‌ها به خط بعد منتقل می‌شوند. 

<FlowPane hgap="10" vgap="10">

<Button text="Java"/>
<Button text="Spring"/>
<Button text="Hibernate"/>
<Button text="JavaFX"/>
<Button text="JPA"/>
<Button text="Maven"/>
```
```
``` ┌──────────────────────────────┐ │ [Java] [Spring] [Hibernate] │ │ [JavaFX] [JPA] [Maven] │ └──────────────────────────────┘
```

کاربرد

برای Tagها، Buttonهای متعدد و لیست‌های کوچک Responsive مناسب است.

9. TilePane

TilePane شبیه FlowPane است، اما آیتم‌ها را در خانه‌هایی با اندازه یکسان قرار می‌دهد.

``` ┌─────────┬─────────┬─────────┐ │ Java │ Spring │ JPA │ ├─────────┼─────────┼─────────┤ │ SQL │ JavaFX │ Maven │ └─────────┴─────────┴─────────┘
``` 
<TilePane hgap="10"
      vgap="10"
      prefColumns="3">

<Button text="Java"/>
<Button text="Spring"/>
<Button text="JPA"/>
<Button text="SQL"/>
<Button text="JavaFX"/>
<Button text="Maven"/>
```
```

کاربرد

  • Dashboard
  • کارت‌ها
  • منوهای کاشی‌ای
  • Gridهای ساده

10. Pane ساده

Pane یک Container ساده است که اجازه می‌دهد موقعیت عناصر را به صورت دستی مشخص کنیم. 

<Pane>

<Button text="سلام"
        layoutX="100"
        layoutY="50"/>
```
```

یا در Java:

button.setLayoutX(100);
```

button.setLayoutY(50);
```
برای طراحی Responsive معمولاً استفاده مستقیم از Pane پیشنهاد نمی‌شود، زیرا موقعیت‌های دستی هنگام تغییر اندازه پنجره به صورت خودکار تنظیم نمی‌شوند.

11. ScrollPane

ScrollPane امکان پیمایش محتوایی را فراهم می‌کند که از فضای موجود بزرگ‌تر است. 

<ScrollPane fitToWidth="true">

<content>

    <VBox spacing="10">

        <Label text="اطلاعات"/>
        <TextField/>
        <TextField/>
        <TextField/>
        <TextField/>
        <TextField/>
        <TextField/>

    </VBox>

</content>
```
```

کاربرد

برای فرم‌های طولانی، صفحات تنظیمات و محتوایی که ممکن است از ارتفاع صفحه بیشتر شود مناسب است.

12. SplitPane

SplitPane صفحه را به چند بخش تقسیم می‌کند و کاربر می‌تواند اندازه بخش‌ها را با Drag تغییر دهد. 

<SplitPane>

<VBox>
    <Label text="منو"/>
</VBox>

<TableView/>
```
```
``` ┌────────────┬────────────────────────┐ │ │ │ │ Menu │ TableView │ │ │ │ │ │ │ └────────────┴────────────────────────┘ ↑ قابل جابجایی
```

کاربرد

برای Sidebar و Content، و همچنین محیط‌هایی که کاربر باید بتواند اندازه قسمت‌ها را تغییر دهد، مناسب است.

13. ترکیب چند Layout با یکدیگر

در برنامه‌های واقعی معمولاً فقط از یک Pane استفاده نمی‌کنیم. Layoutها را می‌توان داخل یکدیگر قرار داد. 

BorderPane
```

│
├── TOP
│    └── HBox
│         ├── Label
│         └── Button
│
├── LEFT
│    └── VBox
│         ├── Button
│         ├── Button
│         └── Button
│
├── CENTER
│    └── StackPane
│         └── VBox
│              ├── Label
│              ├── HBox
│              │    ├── TextField
│              │    └── Button
│              │
│              ├── TableView
│              └── Pagination
│
└── BOTTOM
└── Label
```
نکته بسیار مهم: لازم نیست برای کل صفحه فقط یک Layout انتخاب کنید. می‌توانید Layoutها را داخل یکدیگر قرار دهید و هر بخش را با مناسب‌ترین Pane طراحی کنید.

14. مقایسه سریع Layoutها

Layout نحوه چیدمان کاربرد اصلی
VBox عمودی فرم و لیست عمودی
HBox افقی دکمه‌ها و Toolbar
BorderPane ۵ ناحیه ساختار اصلی صفحه
StackPane روی یکدیگر Center، Overlay و Responsive
AnchorPane نسبت به لبه‌ها تعیین فاصله از لبه‌ها
GridPane سطر و ستون فرم‌ها
FlowPane پشت سرهم و Wrap Tagها و آیتم‌های کوچک
TilePane خانه‌های یکسان Dashboard و کارت‌ها
Pane موقعیت دستی موارد خاص
ScrollPane محتوای قابل Scroll محتوای بزرگ
SplitPane قسمت‌های قابل تغییر Sidebar و Content

16. نکته مهم درباره Responsive Design

در طراحی JavaFX بهتر است کمتر از موقعیت‌دهی ثابت مانند layoutX و layoutY استفاده شود.

به جای این:

button.setLayoutX(100);
```

button.setLayoutY(50);
```

بهتر است از ساختار Layout استفاده کنید:

BorderPane
↓
```

Center
↓
VBox
↓
TableView
```

یا در AnchorPane: 

<TableView
AnchorPane.topAnchor="10"
AnchorPane.bottomAnchor="10"
AnchorPane.leftAnchor="10"
AnchorPane.rightAnchor="10"/>

یا در StackPane، محتوا را در مرکز نگه دارید.

نتیجه این است که وقتی Stage بزرگ یا کوچک می‌شود، اجزای صفحه نیز تا حد زیادی به صورت خودکار خودشان را با فضای جدید تطبیق می‌دهند.

17. خلاصه انتخاب Layout مناسب

نیاز شما انتخاب مناسب
چیدن عناصر زیر یکدیگر VBox
چیدن عناصر کنار یکدیگر HBox
ساختار کلی صفحه BorderPane
مرکز کردن یا روی هم قرار دادن StackPane
فاصله نسبت به لبه‌ها AnchorPane
ساخت فرم سطری و ستونی GridPane
آیتم‌های پشت سرهم با رفتن به خط بعد FlowPane
کارت‌ها و خانه‌های مساوی TilePane
اسکرول کردن محتوا ScrollPane
تقسیم صفحه با امکان تغییر اندازه SplitPane
موقعیت‌دهی دستی Pane
